# Publication review companion

The Overleaf editing set has five TeX files: human_readable_main, ai_review, lean_proof_details (standalone), proof_map and the original main. Retired fragments remain in Git history and are explicitly retired in the public snapshot provenance. Original author prose is preserved by tracked additions/removals/replacements; long Lean accounts live in the separate readable supplement.

The current publication queue contains 23 claims, six optional proof routes and 31 curated challenge/library definitions. Definitions remain accessible from signatures even though reference cards are outside the default queue. The independent browser check follows a proved endpoint to its proposition and Field's exact pinned class declaration, checks queue isolation, and finds zero KaTeX errors. The tool suite passes 52 behavioral checks; the paper declaration verifier checks 101 exact names and permitted axioms. These are correspondence/display checks, not a new full kernel replay or human acceptance.

The generic Apache-2.0 generator and frozen supplement are separate repositories. Software tests use miniature independent Git repositories and browser behavior; a custom source-role test establishes use outside Stafford. The frozen supplementary HTML needs no private clone or Lean installation. The current hosted review checks its live version, disables stale sign-offs and preserves notes. The frozen package identifies its source revision explicitly.

Action boxes remain unresolved until the named human checks them. Proposed red wording is not silently accepted. Max's acceptance criterion is the publication statement's hypotheses and conclusion matching a machine-proved endpoint; optional routes enter the queue only if selected by the authors.
