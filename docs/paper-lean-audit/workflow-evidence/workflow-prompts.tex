\subsection{Project prompts and review protocol}

The Stafford archive assigned integration and promotion to one controller.
Workers returned evidence against a frozen task statement, so parallel work
could test distinct proof mechanisms without multiplying the project state.
The project protocol states:

\begin{quote}\small
Workers return evidence. The controller owns authoritative state, integration,
and promotion. Freeze one input statement and dispatch up to four independent
lanes. Each lane gets a declared core budget and scratch directory and returns
only: the command, tool version, input digest, exact output or certificate,
and scope. The controller alone updates the plan, task pool, ledgers, claims,
and proofs.
\end{quote}
