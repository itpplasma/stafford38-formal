# T36 definition ownership

T36 introduces no `def`, `structure`, or `abbrev`. The closure theorem
assembles the existing `ChartSetup`, `CoordinatePresentation`,
`CommonOpenData`, `CommonOpenArcData`, `CommonOpenColumns`, and
`CommonOpenEtaleData` outputs and applies the T22 ring-hom endpoint.
Therefore there is no new definition-owner entry to add.
